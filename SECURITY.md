# Security policy

## Reporting a vulnerability

Report privately through GitHub: open the repository's Security tab and choose
"Report a vulnerability". Please do not open a public issue for a security problem.

We acknowledge reports within three business days and aim to publish a fix or a
mitigation within 30 days, coordinating disclosure with the reporter.

## Supported versions

| Version | Supported |
|---|---|
| Latest 0.5.x and its release candidates | Yes |
| 0.4.1 | Security fixes until 0.5.0 is released |
| Earlier | No |

## What counts

Phaseline makes decisions from declared rules and supplied records. A result that
releases when the rules and records require hold or withhold, a crash or hang on
malformed input, or code execution from a rule or case file are security issues.
